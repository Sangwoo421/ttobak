# 음성 대응 레이어 적용 전/후 측정 결과 (2026-09-10 새벽, 팀원 녹음)

PPT 7번 슬라이드와 Q&A 용. 숫자는 `tools/measure/results/` 의 원본이고, 여기서는 **어떻게 읽어야 하는지**를 적는다.

## 결과

테스트셋: 팀원 5명이 녹음한 어르신 발화 14문장 중 **비교 가능한 10건** (사투리·어눌한 발음·문장 중간 쉼 포함).
같은 STT 엔진(gemini-3.5-transcribe), 같은 wav 파일을 두 경로에 넣었다.

| 경로 | 의도 도달률 | 평균 시도 횟수 | 오실행 건수 |
|---|---|---|---|
| 레이어 미적용 (700ms 절단 · 힌트 없음 · 문자열 포함 대조) | 9/10 (90%) | 2.00 | 0 |
| 레이어 적용 (2000ms 대기 · 어휘 힌트 · 자모 대조 + 게이팅) | 9/10 (90%) | **1.50** | 0 |

- **의도 도달** = 깨진 발화라도 하려던 일(설명·요청·창구)에 닿는 길이 열림. 되묻기·후보 버튼으로 간 것도 도달로 센다.
- **시도 횟수** = 즉시 확정 1, 되묻기 2, 후보 버튼 3. 도달 못 한 건은 3.
- **오실행** = 잘못된 상대·금액이 확정 단계로 들어간 건수. 구조상 0 이 목표이고 0 이었다.

제외 4건은 STT API 가 한쪽 경로에서 빈 문자열을 돌려줘(무료 등급 일일 한도) 비교가 성립하지 않은 것이다. 레이어와 무관한 실패라 표에서 뺐다.

## 레이어가 실제로 한 일 (건별)

| 발화 | 미적용 | 적용 |
|---|---|---|
| "우리 큰애가 돈 좀 부치라 그러는데… (쉼) 그 이십만 원인가" | 쉼에서 잘려 "아니, 그네가 돈 좀 부치라 그러는데"만 들어감 → 후보 버튼 (3회) | 문장 전체 → 큰애=아들 인식 → 되묻기 (2회) |
| "저… 저번에 그… 전기세 그거 얼마 나간 거여" (어눌) | STT "주주주부링크 정기시 월급 얼마" → 상품 질문으로 오판 ✗ | 어휘 힌트로 "전기세" 살아남 → 금액 질문 확정 (1회) |
| "영희한테… 우리 딸… 오만 원만 좀 보내주라" | STT "여름이여들 리덜" → 후보 버튼 (3회) | 딸 김영희 확정 (1회) |
| "세 번째 그 무슨 통신인가 뭐시긴가" | 둘 다 자모 대조로 '대한정보통신' 잡음 (1회) | 〃 |

## 레이어가 진 건 — 발표에서 먼저 말한다

"뭐라꼬 잘 못 들었다 한 번만 더 해봐라"를 STT 가 "마거, 잘 됐다. 한번 와 봐라"로 적었고, 적용 경로는 이걸 전기요금 거래 질문으로 **채택**했다. 돈이 움직이는 판정이 아니라 오실행은 아니지만, 엉뚱한 답을 되묻지 않고 확정한 것이다.
→ 한계: 질문 의도(설명 요청)의 게이팅이 이체 의도보다 느슨하다. 다음 단계에서 질문 의도에도 유사도 하한을 둔다.

## 말할 때

- "자체 구성 테스트셋, 팀원 녹음, 10건" 을 먼저 말한다. 규모가 작다는 건 숨길 게 아니다.
- 도달률보다 **시도 횟수 2.00 → 1.50** 과 **오실행 0** 을 앞세운다. 도달률이 같은 건 버튼으로 떨어진 것도 도달로 치기 때문이다.
- "같은 STT 엔진, 같은 파일이라 차이는 레이어에서만 난다."
- 위의 '진 건'을 먼저 말하고 나서 이긴 건을 말한다. 은행 심사위원은 과장을 바로 알아본다.
