# 심사기준 대응 전략

| 평가항목 | 배점 | 세부기준(원문 요지) |
|---|---|---|
| 적합성 | 10 | 대회 주제와의 관련성 / KB국민은행 고객의 디지털 경험에 실질적 긍정 영향 / 문제 정의·해결 방식의 명확성 |
| 창의성 | 20 | 독창적 접근 / 차별화·혁신 요소 / 유사 사례 대비 새로움 |
| 구현 가능성 | 20 | 개발 목표와 결과물의 일치 / 실제 작동하는 프로토타입·데모 / 기술적 안정성·신뢰성 |
| 발표력·전달력 | 20 | 명확·논리적 구성 / 강점 설명과 질문 답변 / 시각자료·시연의 전달 효과 |
| 기대효과 | **30** | 사회·경제·UX 긍정 영향 / 발전 가능성(추가 개발·상용화) / 확장성(타 분야·플랫폼) |

부가: 성실한 태도, 대회 절차 준수, 결과 발표·시상식 참여. (실격 사유이므로 전원 숙지.)

## 항목별로 "무엇을 증거로 보여줄 것인가"

### 기대효과 30점 — 문서와 발표에서 나온다
심사위원이 30점을 주려면 "이게 되면 세상이 어떻게 달라지는지"가 **숫자·로드맵·확장 사례**로 보여야 한다.
- 숫자: 은행 고객 중 60대 이상 21.2% vs 모바일뱅킹 이용 10.3% → 격차가 잠재 사용자. 요약서 사용 시 상담 시작까지 시간 자체 측정치.
- 로드맵 3단계: KB스타뱅킹 부가 모드 → 영업점 태블릿·번호표·콜센터 전처리 → 전 연령 쉬운 설명 모드 + 계열사 알림.
- 확장: STT 엔진 독립 레이어(다른 음성 서비스 위에 얹기), 대화/판정 분리 구조(규제 산업), 타 도메인(공공 민원·병원 예약).
- 은행 이득: 창구 혼잡 완화, 오안내 리스크 감소, 판정 로그로 민원 사후 검증, 고령 고객 디지털 전환 지표.
- **PPT 마지막 2장 + Q&A 절반**을 여기에 쓴다. Day 3 오전을 통째로 배정.

### 창의성 20점 — 메시지 3개로 고정
1. **실패를 설계한다**: 인식 정확도를 올리는 게 아니라, 인식이 깨져도 하려던 일에 도달하게 한다(후보 대조 → 되묻기 → 버튼).
2. **모르면 지어내지 않고 창구로 넘긴다**: 확인 불가는 실패가 아니라 정상 경로. 창구는 대체가 아니라 연계.
3. **AI 에게 실행 권한을 주지 않는다**: 돈이 움직이는 API 가 시스템에 없다. 신뢰를 설득하지 않고, 믿지 않아도 쓸 수 있게 한다.
- 비교표 1장: 고령자모드(글씨·메뉴) / 신한 AI 음성뱅킹·케이뱅크 AI 이체(완성된 명령 전제, AI 가 실행) / 또박또박(무엇을 물을지 모르는 사용자 전제, 실행 안 함, 창구 연계).

### 구현 가능성 20점 — 목표 = 결과물, 그리고 "신뢰"
- 기획서 구현 목표 ①②③(+④ 측정)이 시연 12단계에 1:1 대응. PPT 에 대응표를 넣는다.
- 라이브 시연 + 백업 영상. 시연이 죽어도 영상으로 즉시 전환.
- 안정성 증거: 규칙 엔진 `rule_id` 로그, 디버그 패널(의도·후보 점수·결정 경로), 측정 결과표, "같은 입력 → 같은 판정".
- 솔직함: "자체 테스트셋 기준", "범위 밖: 실계좌·번호표 실연동" 을 명시. 은행 심사위원은 과장을 바로 알아본다.

### 발표력 20점 — 한 줄 스토리, 리허설 3회
- 스토리: "알림을 누른다 → 읽어준다 → 물어본다 → 모르는 건 창구 목록에 → 깨진 발화로 이체 요청 → 확인 톤 → 요약서 → 직원 화면".
- 발표자 1명(조태석), 시연자 1명(이성우 또는 고현준), Q&A: 기술은 고현준, 데이터·규칙은 안상우, 인프라는 강두형.
- 예상 Q&A 15개 문답집(docs/06). 답은 20초 이내, 모르면 "범위 밖입니다. 다음 단계에서 이렇게 하겠습니다".

### 적합성 10점 — 첫 장에서 끝낸다
- 첫 슬라이드에 트랙명 "디지털 금융약자 지원", "KB스타뱅킹 부가 모드 전제", "새 앱을 만들지 않는다".
- 문제 정의 3문장(잘못 누를까 봐 / 어디를 눌러야 할지 모름 / 기계를 믿지 못함)과 각각의 해결 매핑.

## 시간 배분
개발 60% / 시연 안정화·측정 20% / 발표 자료·리허설 20%.
