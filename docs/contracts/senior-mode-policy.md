# 어르신 모드 응답 정책 (AI 서버, 담당 고현준 / 화면은 이성우)

어르신 모드에서 바뀌는 것은 글씨 크기가 아니라 **대화 방식**이다: 어휘, 속도, 정보량, 말투, 그리고 못 알아들었을 때의 동작.

## 1. 문장 규칙
- 한 문장에 한 가지 정보. 한 턴에 한 가지 질문.
- 숫자는 한국어 수사로 읽는다: 300,000원 → "삼십만 원", 42,000원 → "사만 이천 원", 3,500원 → "삼천오백 원".
- 날짜는 상대 표현: 오늘 / 어제 / 그저께 / N일 전 (+ "아침/오후/저녁"). 시각 숫자는 말하지 않는다.
- 되묻기가 기본이다. 확신이 없으면 실행하지 않고 묻는다.
- 존댓말. 종결은 "-요"(친근 톤) 또는 "-습니다/-습니까"(확인 톤).

## 2. 생활어 치환표 (LLM 시스템 프롬프트와 템플릿 공통)

| 금융 용어 | 생활어 |
|---|---|
| 출금 | 나간 돈 |
| 입금 | 들어온 돈 |
| 이체 / 송금 | 보내기 / 보낸 돈 |
| 수취인 | 받는 사람 |
| 잔액 | 남은 돈 |
| 적요 | 통장에 적힌 이름 |
| 자동이체 | 매달 자동으로 나가는 돈 |
| 거래내역 | 들어오고 나간 돈 |
| 계좌 | 통장 |
| 영업점 | 은행 / 창구 |
| 본인 확인 | 신분증 확인 |

## 3. 톤

| tone | 언제 | 문체 | TTS |
|---|---|---|---|
| `friendly` | 브리핑, 설명, 되묻기 | "-요", 부드럽게, 짧게 | speed 0.85, instructions: "밝고 또렷한 30대 여성 은행 안내원의 목소리로, 어르신 고객에게 안내하듯 천천히 또박또박 읽는다. 문장 사이에 짧게 쉰다. 목소리를 늙거나 떨리게 만들지 말 것." |
| `confirm` | CONFIRM 상태, 요약서 확정, 되돌리기 어려운 행위 직전 | "-습니다/-습니까", 항목을 하나씩 끊어 읽음 | speed 0.8, instructions: "같은 30대 여성 은행 창구 직원이 중요한 내용을 확인하듯, 단어 사이를 띄어 또박또박 읽는다. 톤을 살짝 낮추고 속도를 더 늦춘다. 목소리를 늙게 만들지 말 것." |

화면도 함께 바뀐다(이성우): confirm 톤이면 배경색·테두리를 바꾸고 버튼을 "맞아요 / 아니에요" 두 개만 크게.

## 4. 템플릿 (LLM 없이 결정적으로 생성)

**브리핑** (`session/start`)
```
{이름} 님, 들어오고 나간 돈 {n}가지를 읽어드릴게요.
첫째, {상대시각} {spoken_name}이(가) {금액} {보내셨어요|나갔어요}.
둘째, …
셋째, …
더 궁금한 게 있으면 말씀하세요.
```
- IN + PERSON: "{spoken_name}이 {금액} 보내셨어요."
- IN + INSTITUTION: "{spoken_name}에서 {금액} 들어왔어요."
- OUT + INSTITUTION/PERSON: "{spoken_name}으로 {금액} 나갔어요."
- OUT + UNKNOWN: "{spoken_name}으로 {금액} 나갔어요." (spoken_name = "'대한정보통신'이라는 곳")

**설명** (`EXPLAIN`)
- CONFIRMED: "{spoken_name}이 보내신 돈이에요. 등록된 {relation} 통장에서 왔어요."
- PARTIAL: "{spoken_name}에서 나간 {category}예요. 자세한 내역은 제가 볼 수 없어요."
- UNKNOWN: "통장에는 '{counterparty_name}'이라고만 적혀 있어서, 무슨 돈인지는 제가 알 수 없어요. 창구에서 여쭤볼 목록에 적어둘까요?"

**확인** (`CONFIRM`, tone=confirm)
```
확인하겠습니다. 받는 사람, {relation} {name}. 금액, {금액}. 맞습니까?
```
**요청 접수 후**
```
이체는 창구에서 직원이 도와드려요. 요약서에 적어둘게요.
```
**되묻기** (`ASK_AGAIN`)
```
{후보 label} 말씀이세요?
```
**못 알아들음** (`CLARIFY`)
```
잘 못 들었어요. 이 중에 있나요?
```
**요약서** (`SUMMARY`)
```
창구 갈 준비가 됐어요. {준비물 문장}. 번호표 {n}번이에요. 창구에서 이 화면을 보여주세요.
```
- 준비물 문장: 신분증만 → "신분증만 가져가세요" / 신분증+통장 → "신분증하고 통장을 가져가세요"

**직원 처리 완료** (status 폴링 → DONE)
```
창구에서 처리됐어요. 수고하셨어요.
```

## 5. LLM 사용 범위 (설명 문장만)
시스템 프롬프트 요지:
- 너는 은행 앱의 안내 음성이다. 아래 facts 에 있는 것만 말한다. facts 에 없는 이유·기관·금액·날짜를 지어내지 않는다.
- 두 문장 이내, 한 문장에 한 정보, 생활어 치환표를 따른다, 종결은 "-요".
- 모르는 것은 "제가 알 수 없어요"라고 말하고 창구 안내로 잇는다.
- 출력은 JSON `{ "text": "...", "used_facts": [..] }` (구조화 출력).

사후 검증(P1): 응답 text 에서 숫자·고유명사를 뽑아 facts 문자열에 없으면 템플릿으로 대체하고 `debug.llm_rejected=true`.

## 6. 화면 규칙 (이성우)
- 버튼 최소 높이 72px, 글자 22px 이상, 한 화면에 버튼 3개 이하.
- 음성 응답 텍스트는 항상 화면에도 크게 표시(청각 보조).
- 마이크 상태를 색과 글로 표시: "듣고 있어요" / "생각 중이에요" / "말씀하세요".
- 어떤 상태에서도 "그만" 버튼이 보인다.
